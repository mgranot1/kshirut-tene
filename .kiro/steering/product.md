# Product Overview

Kshirut Tene is a military equipment readiness tracking and reporting system for the IDF (Israel Defense Forces). The application provides comprehensive dashboards and reporting tools for monitoring equipment status, faults, and operational readiness across organizational hierarchies.

## Core Functionality

- **Dashboard System**: Customizable screens with various chart types (pie, bar, percentage graphs) for visualizing equipment readiness (kshirut) data
- **Equipment Tracking**: Monitor equipment status, faults, and maintenance across organizational levels and equipment families
- **Fault Management**: Track and report equipment faults with severity levels and resolution status
- **Organizational Hierarchy**: Navigate through military organizational structures (צו ארגון) with drill-down capabilities
- **Custom Screens**: Create, save, and share custom dashboard configurations with filters and components
- **Reporting**: Generate kshirut reports with export to Excel functionality

## User Interface

- RTL (Right-to-Left) interface in Hebrew
- Dual-mode operation: Report mode and Dashboard mode
- Role-based access control with unit-level permissions
- Works in both army network and demo/development environments
